Прочитай AGENTS.md, context/README.md, context/defense/README.md и contract.md. Реализуй интерфейс D1 в существующей React-панели. Backend ждать не нужно: используй fixture gateway с теми же запросами и ответами.

## Выполнить

- [ ] Расширить TS-типы, парсер, gateway и controller по D1. Читать state 1.4, сохранив совместимость со старыми версиями; отсутствие health capability не означает поддержку navigation.
- [ ] Добавить выбор «Исследование» / «В заданную точку»; навигационный профиль easy/static/1. Для navigation — числовые координаты X/Y и выбор точки кликом по карте. Достаточна одна точка; редактор многошагового маршрута не нужен.
- [ ] Корректно преобразовывать координаты canvas в систему карты с origin/resolution, масштабом, отступами и перевёрнутой экранной осью Y. Клик вне карты игнорируется с понятным пояснением. Проверить отрицательные координаты, resize и разные pixel ratio.
- [ ] Показать выбранную цель до отправки; клик сам по себе не двигает робота. Кнопка запуска отправляет точную цель и map_id. При обновлении карты/потере связи требовать актуальной проверки; не утверждать достижимость только по проверке UI.
- [ ] Пока миссия активна, не позволять незаметно подменить цель. Показать отдельно пользовательскую цель, текущий маршрут/подцель, движение, достижение цели, возврат и финальный исход. «Достиг цели» не равно «миссия завершена».
- [ ] Сохранить Stop, unknown-outcome/retry с тем же request_id, reconnect, freshness и экспорт. Для ошибок D1 дать понятные сообщения, без сырых транспортных деталей.
- [ ] Сделать fixture-сценарии: pending/moving/reached-returning/completed, стена/карта изменилась/отказ/Stop/stale. Добавить meaningful tests геометрии клика, контрактов и управления; npm test и npm run build.
- [ ] Визуально проверить desktop и узкое окно доступным браузером: подписи, кнопки, легенда, выбранная точка, путь, результат; числовой ввод доступен с клавиатуры.
- [ ] Записать commit, тесты, screenshots и оставшиеся ограничения в reports/agent-2.md; передать агенту 3 точный пользовательский сценарий.
