- **Стенд.** Compose-проект `did-defense`: ROS domain 91, partition `did-defense`, панель :8090, noVNC :6090. Других проектов не трогал.

- **UI.** Проходился в headless Chrome через CDP (`scripts/defense/ui_drive.mjs`): мышь и клавиатура. Расширение Claude in Chrome не было подключено. HTTP использовался только для чтения state и журнала и для отдельного помеченного дополнения: 409 `map_changed`, идемпотентность.
