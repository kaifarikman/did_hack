# DID Hack: контекст проекта

## Быстрый вход

Нужно создать автономного ИИ-исследователя на TurtleBot3 Burger в Gazebo: найти скрытые образцы, изучить стоимость перемещения по грунтам, собрать максимум образцов и вернуться на базу с ограниченной батареей. Исследовательский цикл: гипотеза → действие → наблюдения → вывод → новая гипотеза.

Платформа по ТЗ: ROS 2 Jazzy, Gazebo Sim Harmonic, `turtlebot3_world`. LLM выбирает подцели; алгоритмический исполнитель управляет движением. В hard изменения среды не объявляются агенту.

- В репозитории на момент разбора были PDF задания и LICENSE; реализации, конфигурации среды и судьи нет.
- Пользователь выбрал Docker для запуска стека. На текущем Mac ARM64 проверены работающий Docker Desktop, Linux ARM64 engine и Docker Compose; детали в `environment.md`.
- Пользователь запросил пул задач MVP для двух независимых агентов и чистую архитектуру. Подготовлены два потока: A — backend/ROS/симуляция и интеграция; B — frontend/панель/журнал.
- Рабочая архитектура, общий HTTP-контракт, примеры и критерии приёмки находятся в `mvp/`. Frontend реализован в `frontend/` и проверен автономно; остаётся полная визуальная и сквозная проверка. В `backend/` есть ядро, HTTP и LLM-адаптеры; готовность интеграции отмечается в `mvp/backend.md`.
- LLM настроена в локальном `.env`: реальный запрос через планировщик успешно проверен 2026-10-06; подробности и границы проверки в `environment.md`. Выполнение целой миссии с LLM этим не подтверждено.
- Пользователь расширил цель до всего кейса и всех бонусов, без сокращения объёма ради времени. Текущий целевой план — `full-solution/`: архитектура, F01–F22, матрица требований и протокол доказательств. Включены easy/medium/hard, научный цикл, адаптация, SLAM, два робота, совместный режим, скиллы и показ. Конкретные проектные пороги предложены для проверки, не являются правилами организаторов.
- `mvp/README.md` задаёт первый рубеж, а не конечный объём. `approach.md` сохраняет первоначальные идеи. Целевое разделение полного решения: A — среда/ROS/судья/SLAM; B — агент/исследования/координация/панель; новые задачи пока не считаются выполненными.

## Как поддерживать контекст

Факты из ТЗ сопровождаем страницей источника. Предложения и предположения обозначаем явно. Ответы на вопросы переносим в соответствующий тематический файл; здесь оставляем актуальный статус и следующий шаг. При расхождении пересказа с PDF сверяемся с PDF и записываем неоднозначность.
