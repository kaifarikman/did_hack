# Примеры HTTP-контракта

Все JSON в этой папке — синтетические примеры для параллельной разработки. Карта прямоугольная и учебная; это не `turtlebot3_world`, не его масштаб и не доказательство прогона. Типы и семантика определены в [контракте](../interface.md).

- [state-idle.json](state-idle.json): состояние до старта.
- [state-running.json](state-running.json): миссия с непроверенной гипотезой и наблюдаемой оценкой грунта.
- [map.json](map.json): небольшая сетка для проверки координат и рисования.
- [journal.json](journal.json): одна страница связанных записей журнала.
- [error.json](error.json): ошибка готовности среды.

Агент B добавляет сценарии returning/completed/stopped/failed, обрыв связи, пустые измерения и пагинацию в собственных тестах/фикстурах. Агент A проверяет свою сериализацию по этим моделям. Правки общих примеров сопровождают согласованное изменение контракта.
