## Что проверено и признано хорошим

- **Палитра.** Teal только у Start и выделения текста. Теней в покое нет ни у одного элемента. `--shadow-float` только у Popover/Tooltip (`rgba(0,0,0,.2) 0 0 4px`). Радиусы только 12/16/20/36/round (`A\census.txt`). `font-feature-settings: "kern" 0` применён.
- **Переполнения.** Нет горизонтальной прокрутки, обрезанного текста и текста мельче 12px ни в одном из 16 сценариев на 1920/1440/1280, ru и en.
- **axe.** 0 нарушений на 16 сценариях × 7 комбинаций, кроме UI-32. Контраст текста проходит (Mist затемнён до `#566263`).
- **Popover/Select/Menu.** Вход — fade + scale 0.95 + сдвиг 4px за 160 мс, `transform-origin` у якоря. Выход — 110 мс (быстрее входа). Открытие, прерванное закрытием, разворачивается с текущего кадра. С клавиатуры (Enter/Esc) — без анимации, как требует 5.1. Шеврон Select поворачивается за 200 мс.
- **Переключатель языка** совпадает с rlt: квадратная иконка-глобус 44×44, `aria-haspopup="menu"`, `aria-expanded`, подсвеченное состояние при открытии, флаги ru/gb, названия на своём языке с `lang`, галочка. Индикатор переезжает по `transform` (0 → 44px за ~200 мс), меню закрывается через 220 мс, фокус возвращается. Текст интерфейса меняется сразу.
- **Tooltip.** Задержка 400 мс, fade + scale за 160 мс, выход 110 мс после 100 мс grace, Esc закрывает.
- **Disclosure** («Предпосылки», записи журнала): clip-path + opacity 260 мс / 180 мс, без анимации высоты. Повторный клик во время закрытия разворачивает с текущего кадра.
- **Таблица 5.3** сработала в живых прогонах (`A\ev-*.txt`): лесенка карточек при загрузке (40 мс), Swap статуса и бейджей датчика (110 → 160 мс), пульс «в эфире», `scale` батареи linear 200 мс, вспышка `commit` при резерве (`hard_events`), Swap плана при fallback и пересмотре с лесенкой шагов, pop-in отметки шага, rise-in гипотез/записей/опасностей, разные движения вердиктов, `verdict-emphatic` у потерянного партнёра, fade брони, кольцо опасности (толстое → тонкое) и рисование маршрута на canvas, slide-in итога прогона, press-scale 0.97 у кнопок, Segmented — бегунок прерываемый, с клавиатуры мгновенный.
- **Reduced motion** не ломает интерфейс: длительности 1 мс, у `data-motion="fade"` — fade 160 мс, пульс и спиннер статичны, Popover открывается чистым fade.
- **Клавиатура.** Логичный Tab-порядок (шапка → форма → Start/Stop → журнал), единый `:focus-visible` (2px Carbon) на всех элементах. Disabled Stop фокусируем и объясняет причину тултипом. Esc закрывает слои.
- `canvas` карты имеет `role="img"` и живое `aria-label` (позиция робота, число сборов).
- Числа телеметрии не анимируются, используются `tabular-nums`.
