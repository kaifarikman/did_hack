## Отклонения от плана и причины

1. **`css-duplicates`** не считает «связочные» свойства раскладки и пользовательские `--*`. Без этого любые два flex-контейнера с `align-items`/`gap` давали ложное нарушение. Повторы оформления вынесены в `compose.module.css`. Если нужна буквальная проверка, ответьте — включу.
2. **Сигнальные цвета** `--signal-attention`/`--signal-critical` (ochre и brick из ряда `--data-*`) используются вне карты: в полосе `Meter` и значке `Stat`. В интерфейсном слое Zoox нет цвета предупреждения. Состояние всё равно дублируется иконкой.
3. **Пустые файлы F2-неймспейсов** создал F1: без них не собирается `resources.ts`. F2 создал свои. При слиянии будет add/add-конфликт, оставить версию F2.
4. **`src/domain/status.ts`** сделан по просьбе F2 (раздел 6.4 контрактов) раньше FS-07.
5. **Добавлен `TextField`** в сигнатуры второй волны: он нужен форме миссии.
6. **Biome переформатировал файлы F1** (`domain`, `application`, `adapters/httpGateway.ts`, старые тесты). Файлы F2 исключены override-ом в `biome.json`: `src/ui/*.{ts,tsx,css}`, `src/adapters/fixture/**`, `src/domain/presentation.ts`, `tests/fixture.test.ts`. F2 убирает их из override по мере переноса. Из-за переформатирования в базе file-length выросли числа (например, `missionController.ts` 575 строк).
7. **`rolldown` и `postcss`** — транзитивные зависимости vite 8. Новых зависимостей в `package.json` нет.

### Не закрыто

- Примитивы на `Card tone="inverse"` (`Meter`, `Stat`, `ProgressSteps`, поля) не перекрашиваются. Глобальная перекраска `--text-*` внутри inverse ломала поля и бейджи на светлой подложке, поэтому её откатили. В фичах F2 inverse-карточек нет.
- Мелочи критики закрыты решениями координатора (раздел выше). Не тронут только отступ шеврона `Disclosure`.
- Детектор impeccable отмечает Inter и плоскую шкалу текста. Это ложные срабатывания для Zoox, игнор в конфиг детектора не вносился: пользователь его не подтверждал.
- `Disclosure` закрывает `details` только после перехода. Около 180ms скринридер ещё видит содержимое; запасной таймер гарантирует закрытие.
- Анимации на `@starting-style` проверены только в Chromium. Где его нет (старые Safari и Firefox), слои появляются без входной анимации, выход работает.

### Тонкости

- Прерываемые слои держатся на `@starting-style` и переходах. Если вернуть keyframes, тест `motionReview.test.tsx` упадёт: он требует `@starting-style` и отсутствие `animation:` в CSS `popover`, `tooltip` и `banner`.
- `useDetailsMotion` перед `setState("open")` вызывает `getBoundingClientRect()` у содержимого. Это фиксирует закрытый стиль, иначе Chromium не запустит переход из скрытого `details`.
- Переход `Segmented` берёт стартовую точку из `effect.getComputedTiming().progress` прерванной анимации; радиус читается из `--radius-button` через `readPixels`.
- `hover-gate` проверяет только CSS Modules и `shared/styles`. Старый глобальный `src/ui/styles.css` ловит `css-modules`.
- В `tests/checks/unity.test.ts` и `motionUsage.test.ts` хук impeccable находит `side-tab` и `overused-font`. Это фикстуры проверок, а не дизайн.
