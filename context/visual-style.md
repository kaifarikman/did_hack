# Визуальный стиль «Лаборатория»

> Графит, научный зелёный и много воздуха. Янтарь только у образцов.

Статус: палитра и шрифты **утверждены** пользователем для презентации 2026-10-07. Перенос на веб-панель — **предложение команды**, панель пока использует свои цвета (`frontend/src/ui/styles.css`, `frontend/src/ui/mapRenderer.ts`).

Эталон: [`presentation/goatwhistle.html`](../presentation/goatwhistle.html). Откройте его, нажмите `R` на любом слайде, и вы увидите все анимации из этого гайда.

---

## Характер в трёх словах

**Точный.** Сетка, ровные отступы, ничего лишнего. Карта и данные важнее украшений.

**Живой.** Движение показывает работу агента: робот едет, гипотеза проверяется, точка бежит по циклу. Движение не служит украшением.

**Спокойный.** Один акцент на экран. Зелёный показывает действие и путь, янтарь — цель исследования, то есть образцы.

### Правила цвета

- **Зелёный означает «агент действует»:** пройденный путь, текущая подцель, активный шаг цикла, кнопка Start.
- **Янтарь означает только образец.** Не используйте его для предупреждений, ссылок и выделения, иначе образцы потеряются.
- **Медленный грунт** рисуем серо-зелёной штриховкой `#8A9A92` под 45°, без заливки цветом.
- **Цвет не работает один.** Статус, риск и победитель всегда подписаны словом: «Батарея 18%, возвращаемся».
- Чистые `#000` и `#FFF` не используем.

## Типографика

Два семейства:

| Шрифт | Где | Начертания |
| --- | --- | --- |
| **IBM Plex Sans** | Весь интерфейс и текст | 400, 500, 600, 700 |
| **JetBrains Mono** | Только данные: координаты, время, проценты, ID прогонов, даты | 500, 700 |

Моноширинный шрифт нужен для данных, а не как «технический костюм». Цифры в таблицах и счётчиках ставим с `font-variant-numeric: tabular-nums`, чтобы они не прыгали при обновлении.

### Шкала

| Роль | Слайд 1920×1080 | Панель (веб) | Насыщенность |
| --- | ---: | ---: | --- |
| Дисплей | 104 | 32 | 700, трекинг −0.025em |
| Заголовок | 64 | 24 | 700, трекинг −0.015em |
| Подзаголовок | 44 | 18 | 600 |
| Текст | 32 | 15 | 400, межстрочный 1.45 |
| Подпись | 24 | 13 | 400–500 |

Выделяем насыщенностью или цветом, а не новым размером. Заголовки делаем с `text-wrap: balance`.

### Подключение шрифтов

Панель запускается в Docker, а на площадке может не быть интернета. Поэтому шрифты лучше положить в `frontend/public/fonts/` как woff2 (кириллица и латиница) и подключить через `@font-face`. Подходят вариативные файлы: один файл покрывает 400–700. В презентации те же файлы вшиты в HTML через base64.

## Сетка и отступы

Шаг 8 px: `8 · 16 · 24 · 32 · 48 · 64 · 96 · 128`.

- **Внутри группы** отступы плотные, 8–16. **Между группами** — щедрые, 48–96. Над заголовком места больше, чем под ним.
- **Скругления:** 16 px у карточек и панелей, 8 px у мелких элементов, 999 px у плашек и чипов.
- **Глубина** передаётся рамкой 1 px в цвет `--*-line`, а не тенью. Тень оставляем только плавающим элементам вроде панели управления: `0 8px 24px rgba(5, 8, 7, 0.4)`.
- **Колонки делим тонкой вертикальной линией**, а не обводкой каждой карточки, как на слайде «Команда».

## Компоненты

**Плашка (pill).** Высота около 44 px, паддинг 14×28 на слайде и 4×12 в панели, радиус 999. Главная плашка залита `--accent`, текст `--ink`. Остальные прозрачные, рамка 2 px `--ink-line`.

**Список с чертой.** Вместо точки ставим короткую черту 22×3 px с радиусом 2 в цвет акцента: `--accent` на тёмном, `--accent-ink` на светлом.

**Узел с ореолом.** Карточка шага или скважины в активном состоянии получает рамку 2 px акцентом и мягкий ореол: `box-shadow: 0 0 0 10px rgba(27, 122, 71, 0.14)`. Неактивный узел остаётся с рамкой `--paper-line`.

**Легенда.** Значок 28 px и подпись 24 px на слайде (14 px и 12–13 px в панели), записи в одну строку (`white-space: nowrap`).

**Фокус.** `outline: 3px solid var(--accent); outline-offset: 3px`. Выделение текста: фон `--accent`, текст `--ink`.

**Иконки.** Только SVG одной толщины линии 1.8–2 в сетке 24 × 24, без эмодзи и символов Юникода вместо иконок.

## Карта арены

Карта — главный визуальный объект, поэтому её цвета закреплены отдельно.

| Объект | Тёмная тема | Как рисуем |
| --- | --- | --- |
| Свободная клетка | `#1A211E` | Заливка |
| Неизвестная клетка | `#111614` | Заливка, без сетки |
| Препятствие, столб | `#2C3832` | Заливка |
| Стена арены | `#2C3832` | Линия 3 px |
| Пройденный путь | `#2FBF71`, 75% | Линия 4 px, скруглённые стыки |
| Запланированный путь | `#2FBF71` | Пунктир `6 12`, бегущий |
| Робот | `#111614` + обводка `#2FBF71` | Круг и короткая черта направления |
| База | `#F3F5F2` + ядро `#111614` | Скруглённый квадрат |
| Образец | `#F2B84B` | Точка, вокруг расходящиеся круги |
| Собранный образец | `#F2B84B`, 40% | Точка без кругов |
| Медленный грунт | `#8A9A92`, 55% | Штриховка 45°, шаг 14 |
| Оценка грунта | `rgba(47, 191, 113, α)` | Заливка, α = 0.12 + 0.25 × уверенность |
| Опасная зона | `#F28B82` | Штриховка и подпись словом |

Сейчас в `mapRenderer.ts` у робота красный, у пути синий, у цели фиолетовый. При переходе на этот стиль роли сохраняются, меняются только цвета.

## Движение

### Кривые и длительности

```css
--ease-expo: cubic-bezier(0.16, 1, 0.3, 1);   /* появление, отклик */
--ease-io:   cubic-bezier(0.65, 0, 0.35, 1);  /* прорисовка, переходы */
```

| Что | Длительность |
| --- | --- |
| Наведение, нажатие | 150–200 мс |
| Появление элемента | 700–900 мс |
| Уход экрана | 420 мс |
| Прорисовка линии | 700–2000 мс, по длине |
| Бесконечный цикл | 1.2–11 с |

### Словарь анимаций

| Имя | Что делает | Где уместно |
| --- | --- | --- |
| `enter-title` | Подъём на 28 px, размытие 10 → 0, маска сверху вниз | Заголовок экрана |
| `enter-rise` | Подъём на 24 px с размытием 6 → 0 | Текст, карточки, строки |
| `enter-pop` | Масштаб 0.3 → 1 | Узлы, точки, плашки |
| `grow-x` | Рост по ширине слева направо | Разделители, полосы прогресса |
| `draw` | Прорисовка штриха (`pathLength="1"`) | Маршруты, оси, дуги цикла |
| `march` | Бегущий пунктир | Запланированный путь, поток данных |
| `ping` | Круг расходится и гаснет | Образец, активный узел, база |
| `token` | Точка едет по пути (`animateMotion`) | Робот, шаг цикла, ход времени |
| `leave` | Исчезновение, масштаб 0.985, размытие 6 | Уход экрана |

Задержки задаём переменной `--d` с шагом 60–120 мс. Элементы появляются в порядке чтения: заголовок → текст → визуал → подписи.

### Правила движения

- **Одна хореография на экран.** Новый экран появляется один раз. Обновления данных по опросу не перезапускают анимацию появления.
- **Бесконечное движение означает живое состояние.** `march`, `ping` и `token` крутятся только у того, что действительно идёт: робот едет, гипотеза проверяется, прогон активен. На паузе и после завершения всё замирает.
- **Состояние по умолчанию видимое.** Анимация описывает только начальный кадр (`from`), так что без JS и при печати всё на месте.
- **Уважаем `prefers-reduced-motion`:** длительность 1 мс, бесконечные циклы и бегущие точки скрыты.
- Анимируем `transform`, `opacity`, `filter`, `clip-path` и `stroke-dashoffset`. Ширину и высоту не анимируем.

---

## Чего не делаем

- Надписи-«кикеры» над заголовком. Заголовок говорит сам.
- Градиентный текст, стекло и размытие ради украшения.
- Цветную полосу слева у карточек и алертов.
- Одинаковые карточки «иконка + заголовок + текст» как основу экрана.
- Янтарь где-либо, кроме образцов.
- Моноширинный шрифт для обычного текста.
