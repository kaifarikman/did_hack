# Локальный судья (`judge_mode = local`)

Ядро (`did_judge/engine.py`, `scenario.py`, `occupancy.py`, `config.py`) не импортирует ROS; `ros_node.py` — адаптер.
Истинные образцы и грунтовые зоны не публикуются: наружу идут `/did/battery`, шумный `/did/sample_sensor`,
`/did/score` (JSON без truth), `/did/events` (JSON `type`, `simulation_time_s`, `battery`) и сервисы `/did/collect`, `/did/finish`.
Все числа в `JudgeConfig` — **допущения проекта**; совместимость с официальным судьёй не заявляется.

| Допущение | Значение по умолчанию |
| --- | --- |
| Батарея / база | 60 / старт (-2.0, -0.5) |
| Сбор | расстояние строго < 0,30 м, образец исчезает после сбора |
| Завершение | успех при расстоянии до базы ≤ 0,40 м и батарее > 0; один раз; после него расход прекращается |
| Датчик | `exp(-d/1.5 м)` до ближайшего несобранного образца + гаусс σ=0,03, обрезка 0..1 |
| Расход | 1,0/м; в грунтовой зоне +2,0/м; поворот 0,1/рад; простой 0 |
| Штрафы | коллизия −1 батареи (по лидару < 0,14 м, пауза 2 с), ложный сбор −2 |
| Счёт | 10 за образец − 1 за коллизию − 2 за ложный сбор |
| Размещение | клетки, достижимые от базы при радиусе робота 0,11 м + запас 0,10 м; ≥0,8 м от базы и друг от друга; зона радиусом 0,5 м, центр ≥1,0 м от базы |

Грунт — только логическая надбавка расхода: скорость и трение в Gazebo не меняются, физического замедления нет.
Положение робота судья берёт из `/odom` + смещение базы (допущение; gz-поза расходится на ~1,4 см).
Настройки переопределяются `config/local_easy.json`. Seed передаётся параметром узла `seed`; reset — через `scripts/supervisor.py`.
