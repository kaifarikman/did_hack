# Frontend: панель наблюдения MVP

React + TypeScript + Vite. Контракт: `context/mvp/interface.md`. Слои: `src/domain` (чистые правила) ← `src/application` (контроллер, порты) ← `src/adapters` (HTTP, демо) и `src/ui`; сборка в `src/main.tsx`.

## Запуск

```bash
npm ci
npm run dev                          # live, прокси /api/v1 → BACKEND_URL (по умолчанию http://localhost:8000), порт 8080
VITE_DATA_SOURCE=fixture npm run dev # демо-данные без backend
npm test && npm run build            # тесты, проверка типов, сборка
npm run sync-examples                # обновить копии общих примеров из context/mvp/examples
```

Демо-режим включается только явно и постоянно показывает метку «Демо-данные»; при потере live-backend панель на фикстуры не переключается. Демо не доказывает работу симуляции.

## Контейнер (для Compose агента A)

- build context: `frontend/`, Dockerfile: `frontend/Dockerfile` (nginx, `0.0.0.0:8080`).
- `BACKEND_URL` — адрес backend для прокси `/api/v1` (по умолчанию `http://backend:8000`); разрешается при запросе, контейнер стартует и без backend.
- `DATA_SOURCE` — `live` (по умолчанию) или `fixture`.
- Секретов LLM нет.

```bash
docker build -t did-frontend frontend
docker run --rm -p 8080:8080 -e DATA_SOURCE=fixture did-frontend                      # демо без backend
docker run --rm -p 8080:8080 -e BACKEND_URL=http://backend:8000 did-frontend          # live
```

Compose: `frontend: { build: ./frontend, ports: ["8080:8080"], environment: { BACKEND_URL: "http://backend:8000" } }`.

## Демо-сценарии (выпадающий список в шапке)

Успешная миссия; отказ LLM → fallback; разрыв связи (9 неудачных опросов ≈ 4,5 с → «Данные устарели» → восстановление); завершение с ошибкой (`failed`); старт отклонён 503 (повтор проходит). Ручная остановка — кнопка Stop в любом сценарии.

## Проверки и результаты (2026-10-06, автономно, без backend)

- `npm test`: 75 тестов (валидация контракта, геометрия на асимметричной повёрнутой карте, оба адаптера на общих примерах, опрос/устаревание/revision/смена прогона/cleanup, команды, журнал и экспорт, демо-сценарии).
- `npm run build`: проверка типов и сборка без ошибок.
- Docker: образ собран; fixture-контейнер отдаёт `/` и `/config.json` на 8080 без backend (прокси даёт 502); live-контейнер с тестовым HTTP-сервером на общих примерах проксирует `/api/v1/state` и `/health`.
